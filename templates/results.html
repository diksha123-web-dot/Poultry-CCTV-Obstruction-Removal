Project Summary

The system compares three obstruction removal techniques using poultry CCTV footage. OpenCV Telea uses traditional inpainting, LaMa uses deep learning for image reconstruction, and ProPainter uses temporal information for video inpainting.

The outputs and performance measurements help evaluate the strengths and limitations of each technique.
